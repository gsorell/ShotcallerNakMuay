# Release Notes — v1.18.0

**Date:** 2026-09-09
**versionCode:** 97
**Type:** Rebrand + logo rebuild. No behaviour change.

---

## Summary

The stores were renamed to **Shot Caller: Muay Thai Timer** on 2026-09-08 but
the app was not, so someone installing from the App Store landed on a home
screen icon reading "Shotcaller Nak Muay" — a name they had never seen. This
release brings the app in line, and replaces the logo with one that has an
actual source.

The brand is **Shot Caller**; everything after the colon is a per-surface
descriptor. A store title is an ASO instrument and a logo is an identity one,
and they are not required to match.

---

## 1. Rename

Six different names were live at once, including a reversed "Nak Muay Shot
Caller" in the PWA manifest. Now **Shot Caller** in:

| Surface | File |
|---|---|
| iOS display name | `ios/App/App/Info.plist` (`CFBundleDisplayName`) |
| Android launcher | `android/app/src/main/res/values/strings.xml` |
| Capacitor | `capacitor.config.ts` (`appName`) |
| PWA manifest | `public/manifest.json` (word order was reversed) |
| Web titles / og / JSON-LD | `index.html`, `public/home.html` |
| Logo alt text | `Header.tsx`, `PWAInstallPrompt.tsx`, `OnboardingFlow.tsx` |
| Onboarding copy | `OnboardingFlow.tsx` |
| Share sheet titles | `src/utils/imageUtils.ts` |
| **Shareable cards** | `WorkoutCompleted.tsx`, `CharmCelebrationModal.tsx` |

The last row was found late, by shooting the store screenshots. Those two
strings are watermarks on the images users post to social, which is a worse
place to leak an old name than a header.

### Deliberately NOT renamed

- **`com.shotcallernakmuay.app`** — a new appId is a new listing with no
  reviews and no install history.
- **`page_title` in `src/utils/analytics.ts`** (3 occurrences) — a new value
  mints a new GA4 dimension and splits every page report. Three reporting
  boundaries already exist; a string no user sees is not worth a fourth.
- **`#ShotcallerNakMuay`** in share captions — "Shot Caller" as a hashtag
  collides with a League of Legends term and a Nipsey Hussle song. The compound
  is distinctive and searchable.
- Repo name, `package.json` name, and the `netlify.app` domain — internal.

## 2. Logo

**There was no editable source.** Every PSD on the machine is flattened raster,
and the wordmark was never typeset — the letterforms belonged to no font, so it
could not be re-set, only redrawn.

It is now generated by **`scripts/build_logo_banner.py`**:

- Type is real text in **Poppins Black**, vendored at `assets-src/fonts/` with
  its OFL. SIL Open Font License means unrestricted commercial and trademark
  use — this ruled out Segoe UI Black, which fit the old letterforms comparably
  well but carries a Microsoft licence.
- Gradient applied programmatically; re-centred so the magenta→cyan crossover
  lands mid-word rather than only reaching cyan on the final "ER".
- Subtitle is a flat amber **sampled from the lightning bolt**, whose warm range
  was otherwise orphaned — nothing outside the bolt used it, so the mark and the
  wordmark shared no palette.
- Header gained a **5% gutter** (`Header.css`). The old logo's margins came from
  its `max-height` cap binding at 3.27:1; the new lockup is 4.62:1, so the cap
  no longer bound and the logo ran edge to edge. A gutter does not depend on the
  logo's aspect ratio.

Only the glove-and-bolt mark is still lifted from the old artwork. It is line
art rather than type and survives rescaling, but **vectorising it is the one
part with no source** — and the reason `logo-shotcaller.svg` is not yet fully
vector.

`assets-src/drafts/` holds the earlier approved-then-superseded versions with
the constants to restore each.

## 3. Store screenshots

**`scripts/store-shots.mjs`** drives the app with `playwright-core` against the
installed Chrome. Seven screens at both store sizes, hit exactly by viewport ×
scale factor rather than resized:

- App Store 6.9" — 1290×2796
- Play phone — 1080×1920

Reachable because `?pro=1` (`devOverride.ts`, compiled out of production) opens
the Pro surfaces, and `dev-seed-charms.js` is injected as an init script so the
log screen has a real 12-day history instead of "No workouts logged yet".

Output goes to `assets-src/store/`, **not** `public/` — 20MB of upload artwork
under `public/` ships in the web bundle and is copied into the native app
assets by Capacitor. Gitignored; regenerates in one command.
